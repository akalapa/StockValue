# คำนำ

> "ราคาคือสิ่งที่คุณจ่าย มูลค่าคือสิ่งที่คุณได้รับ" — Warren Buffett

คู่มือเล่มนี้รวบรวมแนวทางคัดเลือกหุ้นในตลาดหลักทรัพย์แห่งประเทศไทย (SET) และตลาดหลักทรัพย์ เอ็ม เอ ไอ (mai) โดยยึดแนวคิด **การลงทุนแบบเน้นคุณค่า (Value Investing)** ของ Benjamin Graham และ Warren Buffett แล้วปรับให้เข้ากับลักษณะของตลาดหุ้นไทย

หลักการของเล่มนี้มีสามข้อ

1. **ซื้อหุ้นคือซื้อส่วนหนึ่งของกิจการ** ไม่ได้ซื้อเส้นกราฟ
2. **มูลค่าของกิจการมาจากกำไรและกระแสเงินสดในอนาคต** ราคาหุ้นระยะสั้นอาจแกว่งไปไกลจากมูลค่า แต่ในระยะยาวมักกลับมาใกล้มูลค่า
3. **ซื้อเมื่อมีส่วนเผื่อความปลอดภัย (Margin of Safety)** คือซื้อที่ราคาต่ำกว่ามูลค่าที่ประเมินได้มากพอ เผื่อไว้สำหรับกรณีที่เราประเมินผิด

เกณฑ์ตัวเลขในเล่มนี้สอดคล้องกับเครื่องมือ *Value Screener (SET)* ในโปรเจกต์นี้ ใช้เครื่องมือคัดกรองรอบแรก แล้วใช้คู่มือนี้วิเคราะห์ต่อในเชิงลึกได้

> **ข้อควรระวัง:** เนื้อหาในเล่มนี้มีไว้เพื่อการศึกษา ไม่ใช่คำแนะนำให้ซื้อหรือขายหลักทรัพย์ใด การลงทุนมีความเสี่ยง ผู้ลงทุนควรศึกษาข้อมูลก่อนตัดสินใจลงทุน ข้อมูลภาษีและกฎเกณฑ์ของตลาดอาจเปลี่ยนแปลงได้ ควรตรวจสอบกับแหล่งข้อมูลทางการล่าสุดเสมอ

# บทที่ 1 รู้จักตลาดหุ้นไทย

## 1.1 โครงสร้างตลาด

- **SET** เป็นตลาดหลักสำหรับบริษัทขนาดกลางถึงใหญ่
- **mai** เป็นตลาดสำหรับบริษัทขนาดกลางถึงเล็ก มักเติบโตเร็วกว่า แต่ความเสี่ยงและความผันผวนก็สูงกว่า สภาพคล่องต่ำกว่า
- **ดัชนีสำคัญ:** SET Index, SET50, SET100, sSET (หุ้นขนาดเล็ก), SETHD (หุ้นปันผลสูง), SETESG
- หุ้นไทยแบ่งเป็น 8 กลุ่มอุตสาหกรรม เช่น ธุรกิจการเงิน ทรัพยากร เทคโนโลยี บริการ อสังหาริมทรัพย์และก่อสร้าง เกษตรและอุตสาหกรรมอาหาร สินค้าอุปโภคบริโภค และสินค้าอุตสาหกรรม

## 1.2 ลักษณะเฉพาะที่ควรรู้

**ดัชนีกระจุกตัว** หุ้นขนาดใหญ่ไม่กี่ตัวในกลุ่มพลังงาน ธนาคาร โทรคมนาคม และค้าปลีก มีน้ำหนักในดัชนีสูงมาก ดัชนีจึงสะท้อนเศรษฐกิจเก่ามากกว่าเศรษฐกิจใหม่

**ผู้ถือหุ้นใหญ่เป็นครอบครัวหรือภาครัฐ** หลายบริษัทมีครอบครัวผู้ก่อตั้งหรือรัฐวิสาหกิจถือหุ้นใหญ่ ข้อดีคือผลประโยชน์ของเจ้าของกับผู้ถือหุ้นรายย่อยมักไปในทางเดียวกัน ข้อเสียคืออาจมีรายการระหว่างกัน (Related Party Transactions) และนโยบายที่ไม่ได้มุ่งกำไรสูงสุด โดยเฉพาะหุ้นรัฐวิสาหกิจที่อาจถูกใช้เป็นเครื่องมือนโยบาย เช่น ตรึงราคาพลังงาน

**อัตราปันผลสูงเมื่อเทียบกับหลายตลาด** หุ้นไทยจำนวนมากจ่ายปันผลสม่ำเสมอ ทำให้กลยุทธ์หุ้นปันผลเป็นที่นิยม

**สภาพคล่องและ Free Float** หุ้นขนาดเล็กหลายตัวมีการซื้อขายน้อย ซื้อง่ายแต่ขายยาก หรือราคาขยับแรงเมื่อมีคำสั่งขนาดใหญ่ ควรดูมูลค่าการซื้อขายเฉลี่ยต่อวันและสัดส่วนหุ้นที่อยู่ในมือรายย่อย (Free Float) ก่อนลงทุน

**NVDR** คือใบแสดงสิทธิในผลประโยชน์ที่เกิดจากหลักทรัพย์อ้างอิง นักลงทุนต่างชาติมักใช้ถือหุ้นไทยเมื่อสัดส่วนหุ้นต่างด้าว (Foreign Limit) เต็ม ผู้ถือได้ปันผลแต่โดยทั่วไปไม่มีสิทธิออกเสียง การไหลเข้าออกของ NVDR ใช้ดูทิศทางเงินทุนต่างชาติได้

## 1.3 เครื่องหมายและมาตรการที่ต้องสังเกต

ตลาดหลักทรัพย์ขึ้นเครื่องหมายต่าง ๆ บนหุ้นเพื่อเตือนผู้ลงทุน ตัวอย่างที่ควรรู้จัก

| เครื่องหมาย | ความหมายโดยย่อ | ควรทำอย่างไร |
|---|---|---|
| **SP** | ห้ามซื้อขายชั่วคราว (Suspension) มักเกิดจากไม่ส่งงบหรือมีเหตุร้ายแรง | หลีกเลี่ยงจนกว่าจะเข้าใจสาเหตุ |
| **H** | หยุดพักการซื้อขายชั่วคราว (Halt) ระหว่างรอข่าวสำคัญ | อ่านข่าวที่บริษัทแจ้ง |
| **NP / NR** | รอข้อมูลจากบริษัท / บริษัทชี้แจงข้อมูลแล้ว | อ่านคำชี้แจงก่อนตัดสินใจ |
| **C** | Caution เตือนเรื่องฐานะการเงินหรือการดำเนินงาน เช่น ส่วนผู้ถือหุ้นต่ำกว่าเกณฑ์ ผู้สอบบัญชีไม่แสดงความเห็น | เป็นสัญญาณอันตรายสำหรับนักลงทุนเน้นคุณค่า |
| **CB / Cash Balance** | ต้องซื้อด้วยเงินสดเต็มจำนวน มักเกิดจากราคาหรือการซื้อขายผิดปกติ | ระวังการเก็งกำไรและการปั่นราคา |

## 1.4 ภาษีที่ผู้ลงทุนบุคคลธรรมดาควรรู้ (ภาพรวม)

- **กำไรจากการขายหุ้นในตลาดหลักทรัพย์** สำหรับบุคคลธรรมดาได้รับยกเว้นภาษีเงินได้ตามกฎหมายปัจจุบัน
- **เงินปันผล** ถูกหักภาษี ณ ที่จ่าย 10% ผู้ลงทุนเลือกให้จบที่การหัก ณ ที่จ่ายได้ หรือนำไปรวมคำนวณภาษีปลายปีเพื่อขอ **เครดิตภาษีเงินปันผล** ได้ ซึ่งมักคุ้มสำหรับผู้มีฐานภาษีต่ำ (เงินปันผลจากกิจการที่ได้รับยกเว้นภาษี เช่น ส่วนที่ได้รับส่งเสริมการลงทุน BOI ใช้เครดิตภาษีไม่ได้)
- กฎหมายภาษีเปลี่ยนแปลงได้ ควรตรวจสอบกับกรมสรรพากรทุกปี

# บทที่ 2 กรอบการคัดเลือกหุ้น 6 ขั้นตอน

ภาพรวมของกระบวนการทั้งเล่ม

1. **คัดกรองเชิงปริมาณ** ใช้ตัวเลขตัดหุ้นที่ไม่ผ่านเกณฑ์พื้นฐานออก (บทที่ 5)
2. **ทำความเข้าใจธุรกิจ** ธุรกิจหาเงินอย่างไร ได้เปรียบคู่แข่งตรงไหน (บทที่ 3)
3. **อ่านงบการเงินย้อนหลังอย่างน้อย 5 ปี** ดูทั้งการเติบโต ความสม่ำเสมอ และคุณภาพกำไร (บทที่ 4)
4. **ประเมินผู้บริหารและธรรมาภิบาล** (บทที่ 3)
5. **ประเมินมูลค่าและหาส่วนเผื่อความปลอดภัย** (บทที่ 6)
6. **ตรวจสัญญาณอันตรายและวางแผนพอร์ต** (บทที่ 8 และ 9)

ถ้าหุ้นตัวใดตกขั้นใดขั้นหนึ่ง ให้หยุดและพิจารณาตัวถัดไป หุ้นในตลาดมีหลายร้อยตัว ไม่จำเป็นต้องฝืนลงทุนในตัวที่ไม่ชัดเจน

# บทที่ 3 เข้าใจธุรกิจและผู้บริหาร

## 3.1 อยู่ในขอบเขตความรู้ของตัวเอง

ลงทุนเฉพาะธุรกิจที่อธิบายให้คนอื่นฟังได้ภายในไม่กี่ประโยค ตอบคำถามเหล่านี้ให้ได้ก่อน

- บริษัทขายอะไร ให้ใคร ลูกค้าจ่ายเงินเพราะอะไร
- รายได้มาจากธุรกิจหรือลูกค้าไม่กี่รายหรือไม่ (ความเสี่ยงจากการกระจุกตัว)
- ต้นทุนหลักคืออะไร ผันผวนตามราคาสินค้าโภคภัณฑ์ ค่าเงิน หรือค่าแรงหรือไม่
- อีก 10 ปีข้างหน้า ธุรกิจนี้ยังจำเป็นอยู่หรือไม่

## 3.2 ความได้เปรียบเชิงการแข่งขัน (Moat)

ตัวอย่างความได้เปรียบที่พบบ่อยในตลาดไทย

| ประเภท Moat | ลักษณะ | ตัวอย่างประเภทธุรกิจ |
|---|---|---|
| ใบอนุญาต / สัมปทาน | รัฐจำกัดจำนวนผู้เล่น | สนามบิน ทางด่วน คลื่นความถี่ โรงไฟฟ้าที่มีสัญญาขายไฟระยะยาว |
| ทำเลและเครือข่าย | สาขาครอบคลุม ยากจะลอกเลียน | ค้าปลีก ร้านสะดวกซื้อ โรงพยาบาล |
| แบรนด์ | ลูกค้ายอมจ่ายแพงกว่า | อาหาร เครื่องดื่ม สินค้าอุปโภคบริโภค |
| ต้นทุนต่ำ | ขนาดใหญ่ ประสิทธิภาพสูง | ปูนซีเมนต์ วัสดุก่อสร้าง ค้าส่ง |
| ต้นทุนการเปลี่ยนเจ้า | ลูกค้าเปลี่ยนผู้ให้บริการยาก | ซอฟต์แวร์องค์กร ระบบชำระเงิน |

สัญญาณว่า Moat มีอยู่จริงคือ **ROE และอัตรากำไรสูงสม่ำเสมอหลายปี** แม้ในช่วงเศรษฐกิจชะลอตัว

## 3.3 ผู้บริหารและธรรมาภิบาล

- **ผลงานในอดีต** ผู้บริหารทำตามที่บอกไว้ในรายงานประจำปีและการประชุมนักวิเคราะห์ (Opportunity Day) หรือไม่
- **การจัดสรรเงินทุน** นำกำไรไปลงทุนต่อได้ผลตอบแทนคุ้มค่าหรือไม่ จ่ายปันผลและซื้อหุ้นคืนอย่างสมเหตุสมผลหรือไม่ หรือชอบเพิ่มทุนและซื้อกิจการแพง ๆ
- **ผลประโยชน์สอดคล้องกัน** ผู้บริหารถือหุ้นมากพอสมควร ค่าตอบแทนไม่สูงเกินกำไร
- **รายการระหว่างกัน** อ่านหมายเหตุประกอบงบเรื่องรายการกับบุคคลที่เกี่ยวข้อง ถ้ามีมากและเงื่อนไขไม่เป็นธรรม ให้ตัดทิ้ง
- **คะแนนธรรมาภิบาล** ดูผลประเมิน CGR ของสมาคมส่งเสริมสถาบันกรรมการบริษัทไทย (IOD) การเข้าร่วมโครงการแนวร่วมต่อต้านคอร์รัปชันของภาคเอกชนไทย (CAC) และการอยู่ในรายชื่อหุ้นยั่งยืน คะแนนเหล่านี้ไม่ได้รับประกันอะไร แต่ช่วยตัดหุ้นที่ธรรมาภิบาลอ่อนได้

# บทที่ 4 อ่านงบการเงินให้เป็น

อ่านงบย้อนหลังอย่างน้อย 5 ปี ถ้าได้ 10 ปีจะดีกว่า เพื่อให้เห็นผลประกอบการตลอดวัฏจักรเศรษฐกิจ ใช้ **งบการเงินรวม** เป็นหลัก และอ่าน **แบบ 56-1 One Report** ประกอบ

## 4.1 งบกำไรขาดทุน

- **รายได้** โตสม่ำเสมอหรือขึ้นลงตามวัฏจักร
- **อัตรากำไรขั้นต้นและอัตรากำไรสุทธิ** คงที่หรือดีขึ้น แสดงถึงอำนาจในการตั้งราคา
- **แยกกำไรจากรายการพิเศษ** เช่น กำไรจากการขายที่ดิน กำไรจากอัตราแลกเปลี่ยน การกลับรายการด้อยค่า ให้ใช้ **กำไรจากการดำเนินงานปกติ (Core Profit)** ในการประเมินมูลค่า
- **EPS** ควรดูควบคู่กับจำนวนหุ้น ถ้าจำนวนหุ้นเพิ่มขึ้นทุกปีจากการเพิ่มทุนหรือการใช้สิทธิวอร์แรนต์ ส่วนแบ่งกำไรต่อหุ้นของผู้ถือเดิมจะลดลง

## 4.2 งบแสดงฐานะการเงิน

- **สภาพคล่อง** สินทรัพย์หมุนเวียนเทียบกับหนี้สินหมุนเวียน
- **หนี้สินที่มีภาระดอกเบี้ย** สำคัญกว่าหนี้สินรวม โดยเฉพาะหุ้นกู้ที่ใกล้ครบกำหนด
- **ลูกหนี้การค้าและสินค้าคงเหลือ** ไม่ควรโตเร็วกว่ายอดขายมาก
- **ค่าความนิยม (Goodwill)** ที่สูงมากจากการซื้อกิจการ อาจถูกตัดด้อยค่าในอนาคต

## 4.3 งบกระแสเงินสด

กำไรทางบัญชีปรับแต่งได้ แต่เงินสดปรับแต่งยากกว่า

- **กระแสเงินสดจากการดำเนินงาน (CFO)** ควรใกล้เคียงหรือมากกว่ากำไรสุทธิในระยะยาว
- **กระแสเงินสดอิสระ (FCF) = CFO − รายจ่ายลงทุน (CapEx)** คือเงินที่เหลือให้จ่ายปันผล ลดหนี้ หรือลงทุนเพิ่ม
- บริษัทที่ FCF ติดลบต่อเนื่องหลายปีแต่ยังจ่ายปันผลสูง อาจกำลังกู้เงินมาจ่ายปันผล ซึ่งไม่ยั่งยืน

## 4.4 คุณภาพกำไร: คำถามตรวจสอบเร็ว

1. CFO รวม 5 ปี ≥ 80% ของกำไรสุทธิรวม 5 ปีหรือไม่
2. ระยะเวลาเก็บหนี้ (DSO) ยาวขึ้นอย่างผิดปกติหรือไม่
3. มีการเปลี่ยนนโยบายบัญชีหรือเปลี่ยนผู้สอบบัญชีบ่อยหรือไม่
4. ผู้สอบบัญชีให้ความเห็นแบบไม่มีเงื่อนไขหรือไม่ มีวรรค "ความไม่แน่นอนที่มีสาระสำคัญเกี่ยวกับการดำเนินงานต่อเนื่อง" หรือไม่

# บทที่ 5 อัตราส่วนทางการเงินและเกณฑ์คัดกรอง

## 5.1 เกณฑ์ตั้งต้นสำหรับนักลงทุนแบบ Defensive

ดัดแปลงจากเกณฑ์ของ Benjamin Graham และเป็นเกณฑ์เดียวกับที่ใช้ในเครื่องมือ Value Screener (SET)

| # | ตัวชี้วัด | เกณฑ์ | ความหมาย |
|---|---|---|---|
| 1 | P/E | 0 < P/E ≤ 15 | ไม่จ่ายแพงเกินไปเมื่อเทียบกับกำไร |
| 2 | P/B | 0 < P/B ≤ 1.5 | ไม่จ่ายแพงเกินไปเมื่อเทียบกับมูลค่าทางบัญชี |
| 3 | P/E × P/B | ≤ 22.5 | ยอมให้ตัวหนึ่งสูงได้ ถ้าอีกตัวต่ำชดเชย |
| 4 | Current Ratio | ≥ 2 เท่า | สภาพคล่องเพียงพอ |
| 5 | D/E | ≤ 1 เท่า | หนี้ไม่มากเกินส่วนของผู้ถือหุ้น |
| 6 | EPS | > 0 | มีกำไร |
| 7 | ROE | ≥ 15% | ใช้เงินผู้ถือหุ้นได้มีประสิทธิภาพ |
| 8 | ปันผล | จ่ายปันผล | มีวินัยการคืนเงินให้ผู้ถือหุ้น |

เพิ่มเกณฑ์ระยะยาวที่ควรตรวจด้วยตัวเอง

- **กำไรเป็นบวกทุกปี** ในช่วง 5 ถึง 10 ปีที่ผ่านมา
- **EPS เติบโต** อย่างน้อย 30% ในรอบ 10 ปี (เทียบค่าเฉลี่ย 3 ปีแรกกับ 3 ปีล่าสุด)
- **จ่ายปันผลต่อเนื่อง** อย่างน้อย 5 ปี
- **ROE เฉลี่ย 5 ปี ≥ 15%** ไม่ใช่แค่ปีล่าสุดปีเดียว

หุ้นที่ผ่าน 5 ข้อขึ้นไปจากตารางและผ่านเกณฑ์ระยะยาวส่วนใหญ่ ถือว่าเข้ารอบวิเคราะห์เชิงลึก

## 5.2 อัตราส่วนเสริมที่ควรดู

| อัตราส่วน | สูตร | แนวทาง |
|---|---|---|
| อัตรากำไรสุทธิ | กำไรสุทธิ ÷ รายได้ | เทียบกับคู่แข่งในอุตสาหกรรมเดียวกัน |
| ROA | กำไรสุทธิ ÷ สินทรัพย์รวม | ใช้คู่กับ ROE เพื่อดูว่า ROE สูงเพราะหนี้หรือเพราะธุรกิจดี |
| Interest Coverage | EBIT ÷ ดอกเบี้ยจ่าย | ควร > 5 เท่า |
| Net Debt / EBITDA | (หนี้มีภาระดอกเบี้ย − เงินสด) ÷ EBITDA | ควร < 2 ถึง 3 เท่า |
| Payout Ratio | เงินปันผล ÷ กำไรสุทธิ | 40 ถึง 70% ถือว่าสมดุล ถ้าเกิน 100% ต่อเนื่องไม่ยั่งยืน |
| EV/EBITDA | มูลค่ากิจการ ÷ EBITDA | ใช้เทียบบริษัทที่โครงสร้างหนี้ต่างกัน |
| Dividend Yield | ปันผลต่อหุ้น ÷ ราคา | เทียบกับผลตอบแทนพันธบัตรรัฐบาล 10 ปี |

## 5.3 ปรับเกณฑ์ตามอุตสาหกรรม

เกณฑ์ข้างต้นใช้ไม่ได้ดีกับทุกอุตสาหกรรม ต้องปรับตามลักษณะธุรกิจ

**ธนาคารและสถาบันการเงิน** ไม่มี Current Ratio และ D/E สูงโดยธรรมชาติ ให้ดูแทน

- อัตราส่วนหนี้ที่ไม่ก่อให้เกิดรายได้ (NPL Ratio) ยิ่งต่ำยิ่งดี
- อัตราส่วนค่าเผื่อหนี้สงสัยจะสูญต่อ NPL (Coverage Ratio) ยิ่งสูงยิ่งปลอดภัย
- อัตราส่วนเงินกองทุนต่อสินทรัพย์เสี่ยง (CAR) ต้องสูงกว่าเกณฑ์ขั้นต่ำของธนาคารแห่งประเทศไทยพอสมควร
- ส่วนต่างอัตราดอกเบี้ยสุทธิ (NIM) และอัตราส่วนค่าใช้จ่ายต่อรายได้ (Cost-to-Income)
- ใช้ P/B เป็นตัวประเมินมูลค่าหลัก

**ธุรกิจเช่าซื้อและสินเชื่อรายย่อย** ดู NPL อัตราการเติบโตของสินเชื่อ ต้นทุนเงินทุน และการพึ่งพาหุ้นกู้

**อสังหาริมทรัพย์เพื่อขาย** สินค้าคงเหลือ (ที่ดินและโครงการ) สูง Current Ratio มักดูดี แต่ต้องดู Net Debt to Equity ยอดขายรอโอน (Backlog) และอัตราการขาย

**โรงไฟฟ้าและสาธารณูปโภค** D/E สูงได้เพราะมีสัญญาขายไฟระยะยาว ให้ดูอายุสัญญา ความสามารถจ่ายหนี้ และกระแสเงินสดที่คาดการณ์ได้

**ธุรกิจวัฏจักร** (ปิโตรเคมี โรงกลั่น เหล็ก เดินเรือ) P/E ต่ำสุดมักเกิดตอนกำไรสูงสุดของวัฏจักร ซึ่งเป็นช่วงที่ซื้อแล้วเสี่ยงที่สุด ให้ใช้กำไรเฉลี่ยตลอดวัฏจักร (Normalized Earnings) และ P/B แทน

**กองทุนรวมอสังหาริมทรัพย์ / REIT / กองทุนโครงสร้างพื้นฐาน** ไม่ใช่หุ้นสามัญ ให้ดูอายุสิทธิการเช่า (Leasehold หรือ Freehold) อัตราการเช่า และเงินปันผลเทียบกับ NAV

# บทที่ 6 การประเมินมูลค่าและส่วนเผื่อความปลอดภัย

ไม่มีวิธีใดแม่นยำ 100% ควรใช้ **อย่างน้อยสองวิธี** แล้วดูช่วงมูลค่า ไม่ใช่ตัวเลขเดียว

## 6.1 Graham Number

สูตรประเมินมูลค่าแบบระมัดระวัง เหมาะกับธุรกิจที่มีสินทรัพย์จับต้องได้และกำไรสม่ำเสมอ

```
Graham Number = √(22.5 × EPS × BVPS)
```

- **EPS** กำไรต่อหุ้น (ควรใช้ Core EPS หรือค่าเฉลี่ย 3 ปี)
- **BVPS** มูลค่าทางบัญชีต่อหุ้น
- ตัวเลข 22.5 มาจาก P/E 15 × P/B 1.5
- ใช้ได้เฉพาะเมื่อ EPS และ BVPS เป็นบวก
- ข้อจำกัด: ให้มูลค่าต่ำเกินไปกับธุรกิจที่มีแบรนด์หรือสินทรัพย์ไม่มีตัวตนสูงและ ROE สูงมาก

**ตัวอย่าง** EPS = 2.00 บาท, BVPS = 18.00 บาท

Graham Number = √(22.5 × 2 × 18) = √810 ≈ 28.46 บาท

## 6.2 P/E Band และ P/BV Band

เทียบ P/E หรือ P/BV ปัจจุบันกับค่าเฉลี่ยย้อนหลัง 5 ถึง 10 ปีของหุ้นตัวนั้นเอง

- ต่ำกว่าค่าเฉลี่ย −1 SD อาจเป็นจังหวะน่าสนใจ ถ้าพื้นฐานไม่ได้แย่ลง
- ระวัง **กับดักมูลค่า (Value Trap)** หุ้นที่ถูกเพราะธุรกิจกำลังถดถอยถาวร จะถูกต่อไปเรื่อย ๆ

## 6.3 Dividend Discount Model (DDM) แบบง่าย

เหมาะกับหุ้นปันผลที่โตสม่ำเสมอ

```
มูลค่า = D1 ÷ (r − g)
```

- **D1** เงินปันผลต่อหุ้นที่คาดว่าจะได้ปีหน้า
- **r** ผลตอบแทนที่ต้องการ (เช่น 8 ถึง 10% สำหรับหุ้นไทย)
- **g** อัตราการเติบโตของปันผลระยะยาว (ควรระมัดระวัง ไม่เกิน 3 ถึง 5%)

**ตัวอย่าง** D1 = 1.20 บาท, r = 9%, g = 3% → มูลค่า = 1.20 ÷ 0.06 = 20 บาท

## 6.4 Discounted Cash Flow (DCF) แบบย่อ

1. ประมาณการ FCF 5 ถึง 10 ปีข้างหน้าแบบระมัดระวัง
2. คิดลดด้วยอัตราคิดลด (เช่น WACC หรือผลตอบแทนที่ต้องการ)
3. คำนวณมูลค่าสุดท้าย (Terminal Value) ด้วยการเติบโตระยะยาวต่ำ ๆ (2 ถึง 3%)
4. รวมมูลค่า หักหนี้สุทธิ หารด้วยจำนวนหุ้น

DCF อ่อนไหวต่อสมมติฐานมาก ลองเปลี่ยนอัตราคิดลดและอัตราการเติบโตดูหลายกรณี (Sensitivity Analysis) ถ้ามูลค่าเปลี่ยนจากการปรับสมมติฐานเล็กน้อยมาก แปลว่าความไม่แน่นอนสูง ต้องการส่วนเผื่อความปลอดภัยมากขึ้น

## 6.5 ส่วนเผื่อความปลอดภัย (Margin of Safety)

```
Margin of Safety = (มูลค่าที่แท้จริง − ราคาตลาด) ÷ มูลค่าที่แท้จริง
```

แนวทางตีความ (สอดคล้องกับ Value Screener)

| Margin of Safety | การตีความ |
|---|---|
| ≥ 30% และผ่านเกณฑ์ ≥ 5 ข้อ | น่าสนใจมาก ควรวิเคราะห์เชิงลึกทันที |
| 10% ถึง 30% | น่าสนใจ แต่ต้องมั่นใจในคุณภาพธุรกิจ |
| −10% ถึง 10% | ราคาใกล้เคียงมูลค่า รอจังหวะ |
| < −10% | แพงกว่ามูลค่า ไม่ควรซื้อเพิ่ม |

ยิ่งธุรกิจไม่แน่นอน (วัฏจักรสูง หนี้มาก ขนาดเล็ก) ยิ่งต้องการส่วนเผื่อความปลอดภัยมากขึ้น

# บทที่ 7 หุ้นปันผล

นักลงทุนไทยจำนวนมากชอบหุ้นปันผล ซึ่งเป็นกลยุทธ์ที่ดีถ้าเลือกอย่างระมัดระวัง

## 7.1 เลือกปันผลที่ยั่งยืน ไม่ใช่ปันผลสูงที่สุด

- **Payout Ratio** ไม่ควรเกิน 80 ถึง 90% อย่างต่อเนื่อง ยกเว้นธุรกิจที่ไม่ต้องลงทุนเพิ่ม
- **FCF ครอบคลุมปันผล** เงินปันผลควรจ่ายจากกระแสเงินสดอิสระ ไม่ใช่จากการกู้
- **ประวัติการจ่าย** สม่ำเสมออย่างน้อย 5 ถึง 10 ปี รวมถึงช่วงวิกฤต
- **Dividend Yield สูงผิดปกติ** (เช่นเกิน 8 ถึง 10%) มักแปลว่าตลาดคาดว่าปันผลจะลดลง หรือเกิดจากกำไรพิเศษครั้งเดียว

## 7.2 วันที่ควรรู้

- **วันขึ้นเครื่องหมาย XD** ซื้อตั้งแต่วันนี้จะไม่ได้รับปันผลรอบนั้น ราคามักปรับลงประมาณเท่ากับปันผล
- **วันกำหนดรายชื่อผู้ถือหุ้น (Record Date)**
- **วันจ่ายปันผล**

การซื้อก่อน XD เพื่อเก็บปันผลแล้วขายทันที มักไม่ได้กำไรจริง เพราะราคาปรับลงชดเชยและยังต้องเสียภาษีปันผลกับค่าธรรมเนียม

# บทที่ 8 สัญญาณอันตราย (Red Flags)

ถ้าพบข้อใดข้อหนึ่งต่อไปนี้ ให้ตรวจสอบเพิ่มเติมอย่างละเอียด ถ้าพบหลายข้อพร้อมกันให้ตัดทิ้งทันที

## 8.1 สัญญาณจากงบการเงิน

- กำไรโตต่อเนื่อง แต่ **CFO ติดลบหรือต่ำกว่ากำไรมาก** หลายปี
- **ลูกหนี้การค้าหรือสินค้าคงเหลือโตเร็วกว่ายอดขาย** อย่างมีนัยสำคัญ
- **เงินสดในงบสูงแต่กู้เงินเพิ่มเรื่อย ๆ** และจ่ายดอกเบี้ยสูง (เงินสดอาจไม่มีอยู่จริงหรือถูกจำกัดการใช้)
- เงินให้กู้ยืมหรือเงินมัดจำจ่ายให้บุคคลที่เกี่ยวข้องจำนวนมาก
- ผู้สอบบัญชี **ไม่แสดงความเห็น มีเงื่อนไข หรือลาออกกะทันหัน** หรือ **ส่งงบล่าช้า**
- กรรมการหรือ CFO ลาออกหลายคนในเวลาใกล้กัน

## 8.2 สัญญาณจากโครงสร้างทุน

- **เพิ่มทุนบ่อย** โดยเฉพาะการเพิ่มทุนแบบเฉพาะเจาะจง (Private Placement) ในราคาต่ำกว่าตลาดมาก
- **ออกวอร์แรนต์ต่อเนื่อง** ทำให้ส่วนแบ่งกำไรของผู้ถือเดิมลดลง (Dilution)
- ผู้ถือหุ้นใหญ่ **นำหุ้นไปจำนำ** หรือทยอยขายหุ้นอย่างต่อเนื่อง ตรวจสอบได้จากรายงานการเปลี่ยนแปลงการถือหลักทรัพย์ของผู้บริหาร (แบบ 59) บนเว็บไซต์ ก.ล.ต.
- ปรับโครงสร้างธุรกิจ เปลี่ยนธุรกิจหลักบ่อย ๆ ไปตามกระแส

## 8.3 สัญญาณจากตลาด

- ราคาและปริมาณซื้อขายพุ่งผิดปกติโดยไม่มีข่าวพื้นฐานรองรับ
- ถูกขึ้นเครื่องหมาย **C**, **CB** หรืออยู่ในมาตรการกำกับการซื้อขาย
- ข่าวลือหรือคำแนะนำจากกลุ่มแชตและโซเชียลมีเดียที่ชวนให้รีบซื้อ

> **กรณีศึกษา:** ปี 2566 ตลาดหุ้นไทยมีกรณีบริษัทจดทะเบียนขนาดใหญ่ที่ถูกตรวจพบการตกแต่งบัญชี ทำให้ราคาหุ้นและหุ้นกู้เสียหายอย่างรุนแรง สัญญาณหลายข้อในบทนี้ เช่น กระแสเงินสดไม่สอดคล้องกับกำไร การส่งงบล่าช้า และการเพิ่มทุนและออกหุ้นกู้จำนวนมาก ปรากฏให้เห็นก่อนเกิดเหตุ บทเรียนคือ **ขนาดบริษัทและชื่อเสียงไม่ใช่หลักประกัน** ต้องตรวจตัวเลขด้วยตัวเองเสมอ

# บทที่ 9 การสร้างและบริหารพอร์ต

## 9.1 กระจายความเสี่ยงอย่างพอดี

- ถือหุ้นประมาณ **8 ถึง 20 ตัว** ถ้ามีเวลาศึกษาน้อยกว่านี้ อาจลงทุนผ่านกองทุนรวมดัชนีควบคู่ไปด้วย
- **ไม่ให้หุ้นตัวใดตัวหนึ่งเกิน 10 ถึง 15%** ของพอร์ต และไม่ให้อุตสาหกรรมใดเกิน 25 ถึง 30%
- กระจายตามปัจจัยเสี่ยง ไม่ใช่แค่ชื่อหุ้น เช่น ถือหุ้นพลังงานหลายตัวก็ยังเสี่ยงจากราคาน้ำมันตัวเดียวกัน
- พิจารณาการลงทุนต่างประเทศบางส่วน เพราะตลาดไทยมีขนาดเล็กและกระจุกตัว

## 9.2 วินัยการซื้อ

- **ทยอยซื้อ** แบ่งเงินเป็นหลายไม้ ลดความเสี่ยงจากการเลือกจังหวะผิด
- **เขียนเหตุผลการลงทุน** (Investment Thesis) ก่อนซื้อทุกครั้ง: ทำไมถึงซื้อ มูลค่าเท่าไร อะไรคือความเสี่ยง และอะไรจะทำให้เราขาย
- ไม่ใช้เงินกู้หรือบัญชีมาร์จินสำหรับการลงทุนแบบเน้นคุณค่าระยะยาว

## 9.3 เมื่อไหร่ควรขาย

1. **เหตุผลการลงทุนเปลี่ยนไป** พื้นฐานแย่ลงถาวร หรือพบว่าวิเคราะห์ผิด
2. **ราคาสูงกว่ามูลค่าที่แท้จริงมาก** จนไม่มีส่วนเผื่อความปลอดภัยเหลือ
3. **มีโอกาสที่ดีกว่าชัดเจน** หุ้นอีกตัวมีส่วนเผื่อความปลอดภัยสูงกว่าและคุณภาพดีกว่า
4. **พบสัญญาณอันตราย** ตามบทที่ 8

อย่าขายเพียงเพราะราคาลงชั่วคราวโดยที่พื้นฐานไม่เปลี่ยน และอย่าถือต่อเพียงเพราะไม่อยากยอมรับว่าขาดทุน

## 9.4 ทบทวนสม่ำเสมอ

- **ทุกไตรมาส** อ่านงบการเงินที่ประกาศใหม่ และคำอธิบายและการวิเคราะห์ของฝ่ายจัดการ (MD&A)
- **ทุกปี** อ่าน 56-1 One Report เข้าร่วมประชุมผู้ถือหุ้นหรือ Opportunity Day และทบทวนสัดส่วนพอร์ต
- **บันทึกการตัดสินใจ** เพื่อเรียนรู้จากทั้งความสำเร็จและความผิดพลาด

## 9.5 จิตวิทยาการลงทุน

- ตลาดเป็นเหมือน "Mr. Market" ที่บางวันร่าเริงเกินเหตุ บางวันหดหู่เกินเหตุ ให้ใช้อารมณ์ของเขาเป็นโอกาส ไม่ใช่คำสั่ง
- ระวังการยึดติดราคาที่ซื้อ (Anchoring) การตามฝูง (Herding) และการมั่นใจเกินไป (Overconfidence)
- ความอดทนคือความได้เปรียบของนักลงทุนรายย่อย เพราะไม่ต้องรายงานผลรายไตรมาสให้ใคร

- [ ] อธิบายได้ว่าบริษัทหาเงินอย่างไรภายในไม่กี่ประโยค
- [ ] มีความได้เปรียบเชิงการแข่งขันที่ชัดเจนและยั่งยืน
- [ ] ธุรกิจยังจำเป็นในอีก 10 ปีข้างหน้า

# ภาคผนวก ข อภิธานศัพท์

| คำศัพท์ | ความหมาย |
|---|---|
| **BVPS** | มูลค่าทางบัญชีต่อหุ้น = ส่วนของผู้ถือหุ้น ÷ จำนวนหุ้น |
| **CAPEX** | รายจ่ายลงทุนในสินทรัพย์ถาวร |
| **CFO** | กระแสเงินสดจากการดำเนินงาน |
| **Core Profit** | กำไรจากการดำเนินงานปกติ ไม่รวมรายการพิเศษ |
| **Current Ratio** | สินทรัพย์หมุนเวียน ÷ หนี้สินหมุนเวียน |
| **D/E** | หนี้สินรวม ÷ ส่วนของผู้ถือหุ้น |
| **Dilution** | การที่ส่วนแบ่งความเป็นเจ้าของลดลงจากการออกหุ้นใหม่ |
| **EPS** | กำไรสุทธิต่อหุ้น |
| **EV** | มูลค่ากิจการ = มูลค่าตลาด + หนี้สุทธิ |
| **FCF** | กระแสเงินสดอิสระ = CFO − CapEx |
| **Free Float** | สัดส่วนหุ้นที่อยู่ในมือผู้ถือหุ้นรายย่อย |
| **Margin of Safety** | ส่วนต่างระหว่างมูลค่าที่แท้จริงกับราคาตลาด |
| **Moat** | ความได้เปรียบเชิงการแข่งขันที่ป้องกันคู่แข่ง |
| **NVDR** | ใบแสดงสิทธิในผลประโยชน์ที่เกิดจากหลักทรัพย์อ้างอิงไทย |
| **P/B** | ราคา ÷ มูลค่าทางบัญชีต่อหุ้น |
| **P/E** | ราคา ÷ กำไรต่อหุ้น |
| **Payout Ratio** | สัดส่วนกำไรที่จ่ายเป็นปันผล |
| **ROE** | กำไรสุทธิ ÷ ส่วนของผู้ถือหุ้น |
| **Value Trap** | หุ้นที่ดูถูกแต่ถูกด้วยเหตุผลที่ดี และมีแนวโน้มถูกลงต่อไป |
| **XD** | เครื่องหมายไม่ได้รับสิทธิรับเงินปันผล |
