# Value Screener (SET)

หน้าจอคัดกรองหุ้นไทยตามแนวคิด value investing ของ Benjamin Graham / Warren Buffett:
"ราคาคือสิ่งที่คุณจ่าย มูลค่าคือสิ่งที่คุณได้รับ" — เน้นงบการเงินจริง ไม่ใช่กราฟราคา

## สิ่งที่ทำ
- ดึงข้อมูลงบการเงิน/ราคาหุ้นจาก Yahoo Finance (ฟรี, ไม่ต้องใช้ API key) ผ่านไลบรารี `yfinance`
- คำนวณมูลค่าที่แท้จริงแบบระมัดระวังด้วย Graham Number: `sqrt(22.5 * EPS * BVPS)`
- คำนวณ Margin of Safety = (มูลค่าที่แท้จริง − ราคา) / มูลค่าที่แท้จริง
- ตรวจสอบเกณฑ์นักลงทุนแบบ defensive ของ Graham 8 ข้อ (P/E, P/B, current ratio, หนี้สิน, กำไร, ROE, ปันผล)
- แคชผลลัพธ์ไว้ 12 ชั่วโมงเพื่อไม่ให้ยิง request ถี่เกินไป กด "รีเฟรชข้อมูล" เพื่อดึงใหม่ได้ทุกเมื่อ

## วิธีรัน

```bash
cd backend
source ../venv/bin/activate   # หรือสร้างใหม่: python3 -m venv ../venv
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

เปิดเบราว์เซอร์ไปที่ http://localhost:8000

## เพิ่มหุ้นเข้ารายการ
แก้ไข `backend/tickers.py` เพิ่มสัญลักษณ์หุ้นในรูปแบบ `XXXX.BK` (ตามฟอร์แมตของ Yahoo Finance สำหรับหุ้นไทย)

## ข้อจำกัด
- ใช้ข้อมูลฟรีจาก Yahoo Finance ซึ่งบางครั้งอาจไม่ครบทุก field สำหรับหุ้นขนาดเล็ก
- Graham Number ใช้ได้เฉพาะกิจการที่มีกำไร (EPS > 0) และมูลค่าทางบัญชีเป็นบวก
- นี่คือเครื่องมือคัดกรองเบื้องต้นเพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุน ควรอ่านงบการเงินฉบับเต็มก่อนตัดสินใจเสมอ
